Nifsi

Rust / Linux
github.com/phi5ic/Nifsi ↗

An open-source distributed userspace operating system layer written in Rust for Linux clusters. Unifies heterogeneous physical machines into a shared FUSE filesystem, Raft-replicated metadata store, and ChaCha20-Poly1305 encrypted peer mesh. Features a novel HADR (Horizontal & Diagonal Parity) erasure-coding storage engine with 4 KB slice-level homology repair and flat 3.0× write amplification.
